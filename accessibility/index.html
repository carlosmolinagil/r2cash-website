Accessibility

We want everyone to be able to use this website and reach us easily.

Our approach

This website was built with the Web Content Accessibility Guidelines (WCAG) 2.2 level AA in mind. It uses semantic page structure, a logical heading order, labeled form fields, visible keyboard focus, sufficient color contrast and support for reduced-motion settings. Every page can be used with a keyboard alone.

Ongoing work

Accessibility is ongoing. We review the site when it changes and welcome feedback about anything that makes it harder to use.

Report a barrier or request help

If something on this website doesn't work for you, or you need information in a different format, email info@r2cash.com or call +1 (786) 999-2008 (Monday–Friday, 8:00 AM–5:00 PM Eastern Time). Please tell us the page and the problem, and we will respond.
